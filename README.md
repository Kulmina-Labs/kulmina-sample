# kulmina-sample
## Catatan internal

- Setiap sampel ada di folder sendiri: `/<nama-usaha>/index.html` + `logo.jpg` (pakai path absolut `/<folder>/logo.jpg`).
- Semua halaman wajib punya label "contoh desain oleh Kulmina Labs" dan tidak diindeks Google (`vercel.json`, `robots.txt`).
- Animasi standar: `_kit/anim.py` (entrance hero, scroll reveal, hover, progress bar, tombol WA berdenyut; menghormati prefers-reduced-motion).
